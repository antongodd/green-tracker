The plan

  • Everywhere at once. One shared bit of code decides what a touch (or a mouse) does, so every row, card, photo, button, tab and the + gets the same treatment: the Leaderboard, Strainz, Sources, the Feed, product pages, Settings and the sheets.
  • Your Look's colour. The glow uses each of the eleven Looks' own colour. It's kept faint so every word stays readable, and the readability tests check it.
  • Reduce Motion. When it's on, nothing leans, springs or bounces. The press and the glow stay.
  • Nothing else changes. No change to your data, privacy, followers, Export or Restore. The Leaderboard colour effects, the landing show and the Looks' moving backgrounds stay as they are.
  • Size: a big change (it changes how the app feels everywhere), so you'll try it on GT Dev before it goes live.

Questions for you

  1. Which strength: A, B or C?My pick: B. It feels alive but calm, like Apple's own apps. C is fun, but it could get tiring on a screen you use every day.
  2. The same strength for the app and the website?My pick: yes, so they feel like one thing. The website could go one step livelier (C) if you'd like it to show off a bit more.
  3. Should photos lean everywhere, or only the big ones? (the #1 photo, a product page's photo, Feed photos, website cards)My pick: only the big ones, plus a small lean on row photos. Many small tilting things at once looks busy.
